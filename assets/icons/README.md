copied from the local key-manager icon set on 2026-10-29 and are used only for
model identification in the result figures.

| `deepseek.svg` | DeepSeek Flash |
| `gemini.svg` | Gemini 3.8 Flash |
| `longcat.svg` | LongCat 2.5 Preview |
| `minimax.svg` | MiniMax M3.1 Flash |
| `openai.svg` | GPT-6.1 Terra |
| `xiaomi.svg` | MiMo V2.6 Flash (parent brand; no MiMo mark in the source set) |
| `zhipu.svg` | GLM 5.3 Flash |
